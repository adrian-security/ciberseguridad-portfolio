## ¿Qué es una red informática?

Una red informática hace referencia a un conjunto de dispositivos conectados entre sí capaces de compartir información y recursos.

Sirven para compartir información, recursos y acceder a servicios.

**Ejemplos de dispositivos:** PC, teléfono, TV, impresora, altavoz inteligente.

[![Ejemplo de función red](https://i.postimg.cc/WzBd7bxf/9ECE9869-B7C4-487A-A979-B3FFBF0ABC64.jpg)](https://postimg.cc/BPCZSsSx)

### Ejemplo práctico:
Abres el navegador de un dispositivo móvil, este se conecta al router doméstico al que le llega una petición de acceso. El router se encarga de transferir la comunicación **hacia** internet permitiendo que la solicitud llegue al servidor que alberga la página web. El servidor responde y devuelve la información y **aparece** la página web.

---
> 🔒 **Nota de Ciberseguridad:** Comprender este flujo básico es vital, ya que muchos ataques (como *Man-in-the-Middle* o escuchas de tráfico) ocurren precisamente en los puntos intermedios de esta comunicación.
