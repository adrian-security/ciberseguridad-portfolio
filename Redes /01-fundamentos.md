 ## ¿Qué es una red informática?
Una red informática hace referencia a un conjunto de dispositivos conectados entre sí capaces de compartir información y recursos.

Sirven para compartir informacion, recursos y acceder a servicios.

Ejemplo: PC, teléfono, TV, impresora, altavoz inteligente.

Ejemplo de red en casa: abres el navegador de un dispositivo movil, este se conecta al router doméstico al que le llega una petición de acceso. El router se encarga de transferir la comunicación hacía internet  permitiendo que la solicitud llegue al servidor que alberga la página web. El servidor responde y devuelve la información y aoarece la página web.
